 # Floyd Desktop Web v2 - Complete Multimedia API Contracts                                                                                                                                                                                
                                                                                                                                                                                                                                           
 ## 🎯 **Application Understanding**                                                                                                                                                                                                       
                                                                                                                                                                                                                                           
 **Floyd Desktop Web v2** is a **comprehensive multimedia production web application** that provides:                                                                                                                                      
- **Full-featured chat interface** with streaming, file attachments, multimedia support                                                                                                                                                   
- **Real-time collaboration** with sessions, sharing, and cross-device sync                                                                                                                                                               
- **Advanced AI integration** with multiple model providers and vision capabilities                                                                                                                                                       
- **Project management** with workspace organization                                                                                                                                                                                      
- **Settings and customization** with themes and preferences                                                                                                                                                                              
- **Emergency controls** and monitoring capabilities                                                                                                                                                                                      
- **Cross-platform desktop deployment** (Mac, Windows, Linux)                                                                                                                                                                             
                                                                                                                                                                                                                                           
 ---
